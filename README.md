# CPS Test - Clicks Per Second Tester

A modern, pixel-perfect CPS (Clicks Per Second) testing website with a beautiful dark mode design.

## Features

- ⚡ **Real-time CPS Testing** - Measure your clicking speed accurately
- 🎨 **Modern Dark Theme** - Beautiful purple-blue gradient design
- ⏱️ **Multiple Timeframes** - Test from 1 second to 100 seconds
- 📊 **Live Statistics** - Real-time display of timer, clicks per second, and total score
- 🌓 **Theme Toggle** - Switch between light and dark modes
- 🖥️ **Fullscreen Mode** - Immersive testing experience
- 📱 **Responsive Design** - Works on desktop and mobile devices

## How to Use

1. Open `index.html` in your web browser
2. Click in the test area to start the CPS test
3. Click as fast as you can within the time limit
4. View your results: total clicks and CPS score

## Customization

- **Timer**: Use the up/down arrows or click timeframe buttons to set test duration
- **Theme**: Toggle between light and dark mode using the switch
- **Fullscreen**: Click "Open Fullscreen" for an immersive experience
